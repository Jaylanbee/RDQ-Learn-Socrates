# RDQ-Lite 題庫｜Ⅲ 蘇式起始問句 × Ⅳ 蘇式提示

> 本檔供 `SKILL.md` 使用：Phase 0 判學習類型選段、Phase 3 取起始問句、Phase 4 取提示性提問。
> 
> **這不是題目清單，是釣竿庫。** 每一條起始問句都是蘇格拉底對話的出發點——學習者答完，你必須根據他的答案決定追問策略（見 SKILL.md「答覆回應策略」表）。
>
> Ⅲ 起始問句一律按「不問會怎樣」的嚴重度排序。超出互動預算的題不追，記入 ❓ 待確認。
>
> Ⅳ 提示性提問是讓學習者自己發現盲區的存在——你不是告訴他「你少了什麼」，而是問一個讓他意識到「原來還有這個方向」的問題。
>
> 這是**活文件**：實戰中問出好效果的起始問句與追問策略，請回填。

## 通用（所有學習類型都適用）

### Ⅲ 蘇式起始問句（Unknown Knowns）

每條起始問句開啟一段蘇格拉底對話。學習者的回答決定你的追問方向。

| 起始蘇式問句 | 追問策略（依回答分支） | 不問會怎樣 |
|---|---|---|
| 你學了 OOO 對吧。現在不要看任何東西——你腦子裡最先浮出來的一個字或一句話是什麼？ | **→ 他答出具體內容**：「你為什麼第一個想到的是這個？它跟其他部分比，有什麼特別的地方？」 **→ 他答不出來**：「沒關係。那 OOO 這個詞你聽到的時候，你心裡浮現的第一個畫面是什麼？」 | 學習者常高估自己的 recall。真的要他講才發現提取不出來——這是最真實的遺忘曲線檢測。 |
| 如果你現在必須用一句話教會一個完全沒學過的人——你會怎麼說？ | **→ 他講得很清楚**：「你剛才的解釋裡，有沒有哪個詞是你自己發明的，不是課本上的？」 **→ 他講得卡卡**：「卡住的那個地方，你覺得是因為你自己也不確定，還是你覺得對方聽不懂？」 | 教別人是檢驗理解最誠實的方式。能教 = 真的會；卡住 = 漏洞。不測這個，學習者永遠活在「我懂了」的幻覺裡。 |
| 學的過程中，有沒有哪一刻你覺得「原來是這樣！」？ | **→ 有**：「那一刻之前你原本是怎麼想的？是什麼讓你轉過來的？」 **→ 沒有**：「那你會不會其實早就已經知道大部分內容了？你覺得你是真的學了新東西，還是只是複習？」 | 「Aha! 時刻」是認知重構的證據。沒有它，要嘛你本來就會，要嘛你根本沒真的理解。 |
| 你覺得你學的這個東西，是為了解決什麼問題而存在的？ | **→ 能回答**：「這個問題如果不用這個方法，還能用什麼方法解決？」 **→ 不能回答**：「那如果這個東西突然從世界上消失了，你覺得會有什麼事情變得困難？」 | 不知道概念解決什麼問題 = 不知道為什麼要學它。這是最常見的「學了白學」的原因。 |
| 學完之後你最想問但還沒問出口的問題是什麼？ | **→ 有**：「你自己有試著推過答案嗎？你覺得答案最像什麼？」 **→ 沒有**：「真的沒有？那你覺得你學的這個東西有沒有哪個部分讓你覺得『怪怪的』？」 | 沒有問題 = 沒有深度思考。真正的學習一定會產生問題——問題被壓住不問，就會變成日後的誤解。 |

### Ⅳ 蘇式提示性提問（Unknown Unknowns）

不是端菜單讓他勾。是用一個問題讓他**自己發現**「原來還有這個方向」。

| 提示性問句 | 蘇式推進 | 為什麼重要 |
|---|---|---|
| 你確定你學這個東西需要的全部前提知識你都已經穩固了？——你覺得這裡面最「理所當然」的那個假設是什麼？ | 他答「沒有假設」→ 「那如果 A 不成立，你的推論還能成立嗎？」 他答出假設 → 「很好。那你確認過那個假設在現實中真的成立嗎？」 | 多數學習失敗的原因不是新知識太難，而是前提有洞。學習者自己不知道前提的存在。 |
| 你覺得大部分學過這個東西的人，最容易錯在哪裡？——你不是去查，而是你現在直覺覺得哪裡最容易錯。 | 他答出來 → 「那你有沒有檢查過自己有沒有踩到那個陷阱？」 他答不出來 → 「那你回想你學的時候，哪一步你猶豫最久？」 | 知道常見迷思 = 知道自己需要檢查什麼。不知道迷思的人通常自己就踩進去了。 |
| 你學的這個東西，能不能用來解釋一個你完全意想不到的領域？——比如你生活中的某個現象。 | 他想到 → 「這個類比有沒有哪裡是不成立的？界線在哪裡？」 他想不到 → 「那我們換一個：你學的這個，跟『煮飯』有沒有共通點？」 | 能跨域應用才是真正的 understanding。只能原地使用 = 還沒內化。 |
| 你覺得你學的這個版本是最完整的嗎？——有沒有可能你學的是簡化版，真實世界更複雜？ | 他認為就是完整版 → 「如果我要你舉一個你的版本回答不了的情況，你舉得出來嗎？」 他認為可能不完整 → 「那你覺得被簡化的部分是什麼？為什麼被簡化了？」 | 教科書必然簡化。不知道簡化了什麼的人，遇到真實世界的複雜案例會當機。 |

## 概念理解型（理論、定義、原則、模型、分類）

適用：課本章節、理論課程、論文閱讀、知識型書籍、線上課程的觀念篇。

### Ⅲ 蘇式起始問句（Unknown Knowns）

| 起始蘇式問句 | 追問策略（依回答分支） | 不問會怎樣 |
|---|---|---|
| 不要看課本——用你的話重新說一次這個概念，就像在跟隔壁同學解釋一樣。 | **→ 說得順**：「你剛剛說的時候，有沒有哪個字是你自己加的、課本沒有的？」 **→ 卡住**：「你卡住的地方，你覺得是因為你忘了，還是因為你本來就沒搞懂過？」 | 能換句話說才是真的理解。只會背原文的，題目換個包裝就認不出來。 |
| 這個概念跟它最像的那個概念——差在哪？ | **→ 說出差異**：「那這個差異在任何情況下都成立嗎？還是只在某個條件下？」 **→ 覺得一模一樣**：「真的？那為什麼課本要給它們兩個不同的名字？」 | 概念混淆是考試最常見的錯誤來源。沒比較過邊界的人一定搞混。 |
| 你覺得這個理論最大的「弱點」是什麼？——它最怕被問什麼問題？ | **→ 說出弱點**：「如果你的老師在這個弱點上追問你，你怎麼 defend？」 **→ 覺得沒有弱點**：「沒有任何東西是完美的。你只是還沒找到它的假設前提——你覺得它的前提是什麼？」 | 不知道限制 = 遲早誤用。誤用比不會更慘，因為你以為你會。 |
| 你學的這個概念，跟一個你已經很熟悉的東西——做一個比喻。 | **→ 做出比喻**：「這個比喻在哪裡是精準的，在哪裡其實不適用？」 **→ 做不出**：「沒關係。那我做一個給你——你評評看這個比喻好不好。」 | 能類比 = 新知識已經鉚進既有心智模型。不能類比 = 懸浮知識，一個月後忘光。 |
| 你覺得你學的這個定義裡，哪一個字是「拿掉整句話就垮了」的關鍵字？ | **→ 指出關鍵**：「為什麼是那個字？換一個同義詞不行嗎？」 **→ 覺得每個字都一樣重要**：「那我們試試看拿掉『___』——句子還能通嗎？意思變了嗎？」 | 精準理解來自知道邊界在哪。不知道關鍵字的定義 = 死背。 |

### Ⅳ 蘇式提示性提問（Unknown Unknowns）

| 提示性問句 | 蘇式推進 | 為什麼重要 |
|---|---|---|
| 你學的這個理論，有沒有競爭對手？——另一個學派可能用完全不一樣的方式解釋同一件事。 | 沒想過 → 「那你猜猜看，如果一個人不同意這個理論，他會從哪裡開始攻擊？」 想過 → 「你覺得為什麼主流選擇了你學的這個，而不是它的對手？」 | 只學一種觀點的人不知道自己在學的只是「一種說法」，不是「事實」。考試最愛考的「下列何者非…」就是在測這個。 |
| 你確定你學的這個在真實世界一定成立？——你能想到一個它不成立的案例嗎？ | 想不到 → 「那我說一個情境：_____。你的理論在這個情境裡還適用嗎？」 想到 → 「很好。那你覺得課本為什麼不講這個例外？」 | 知道例外 = 真正理解適用範圍。不知道例外的人會在 reality 面前撞牆。 |
| 你學的這個概念，如果拿掉它，整個領域會少了什麼？——它在整個知識地圖裡扮演什麼角色？ | 回答得出來 → 「那如果換一個概念來扮演同樣的角色，你覺得可以嗎？為什麼不行？」 回答不出來 → 「那你學它的時候，課本是把它當主角還是配角在介紹？」 | 不知道概念的相對重要性 = 不知道該投資多少注意力在上面。 |

## 程序操作型（步驟、流程、技能、操作、工具使用）

適用：程式實作、軟體操作、實驗步驟、烹飪流程、運動技巧、樂器演奏。

### Ⅲ 蘇式起始問句（Unknown Knowns）

| 起始蘇式問句 | 追問策略（依回答分支） | 不問會怎樣 |
|---|---|---|
| 現在閉上眼睛——從頭到尾在腦子裡做一次。你到第幾步開始不確定？ | **→ 能順利做完**：「那你怎麼知道你每一步是『真的會』還是只是『記得順序』？——如果其中一步的參數換了，你知道怎麼調嗎？」 **→ 卡在某步**：「卡住的那步，你現在如果看著教學做，你做得出來嗎？還是連看著做都有問題？」 | 最誠實的檢測。「看懂了」跟「做得出來」中間有一道巨大的鴻溝。不跨過去就是上場才發現不會。 |
| 如果過程中某一步失敗了——你第一個檢查的地方會是哪裡？ | **→ 知道檢查點**：「你為什麼第一個檢查那裡？是經驗還是理論告訴你的？」 **→ 不知道**：「那你目前為止有沒有實際失敗過？那次你怎麼解決的？」 | 真正「會了」的標誌不是能做對，而是錯了知道怎麼修。只看成功路徑的人，遇到錯誤就停擺。 |
| 你學的這個流程，哪一步是「錯了後面全白做」的關鍵步驟？ | **→ 指出關鍵**：「那你每次做到那一步的時候，會多做什麼檢查或確認嗎？」 **→ 覺得每步都重要**：「如果時間不夠你一定要跳過一步，你選哪一步？為什麼那步可以跳？」 | 不知道關鍵步驟 = 資源不知道該集中在哪。真正的專業不是什麼都會，而是知道什麼最重要。 |
| 這個做法有幾種不同的方式可以達成？——你學了幾種？ | **→ 知道多種**：「你最常用哪一種？為什麼是它而不是另一種？」 **→ 只知道一種**：「你覺得為什麼教學只教這一種？是這最好，還是這最簡單教？」 | 只會一種做法 = 工具換了就卡死。真正的專業是知道什麼時候用哪種方法。 |
| 如果要你現在教我做——第一步做什麼？ | **→ 能教**：「你教的這個順序，跟你學的時候的順序一模一樣嗎？如果不一樣，你改了什麼？為什麼？」 **→ 卡住**：「你卡住的地方，就是你的 gap。你覺得你需要重看哪一段？」 | 教別人是最好的學習檢測。卡住的地方 = 你以為你會但其實不會的地方。 |

### Ⅳ 蘇式提示性提問（Unknown Unknowns）

| 提示性問句 | 蘇式推進 | 為什麼重要 |
|---|---|---|
| 你走的這條路是「成功路徑」——你有沒有走過「錯誤路徑」？你知道怎麼故意弄錯，再修回來嗎？ | 沒想過 → 「你覺得如果你故意在第三步弄錯，你來得回來嗎？你怎麼知道你來不來得回來？」 想過 → 「那你從錯誤中學到的最重要的一件事是什麼？」 | 只看成功路徑的人，第一次遇到錯誤就卡死。真正會的人玩過所有錯誤路徑。 |
| 你現在的操作方式，有沒有更快的做法？——不是透過練習變快，而是換一個工具或方法。 | 不知道 → 「你猜猜看，做這個動作最慢的部分在哪裡？那裡能不能用 automation？」 知道更快的 → 「那你為什麼現在不用那個更快的方法？有什麼 trade-off？」 | 手動重複做的事情一定有 shortcut。不知道 = 浪費時間。 |
| 你確定你學的做法沒有過時？——這個領域最近有沒有更新、deprecated 或被取代的做法？ | 沒想過 → 「那你學的這個來源是什麼時候的？如果是兩年前的教學，現在可能已經不一樣了。」 知道更新 → 「那你學的這版跟新版比，你覺得哪個比較好理解？」 | 學 outdated 的做法比不學還糟——你還以為你會。 |

## 連結應用型（跨領域、遷移、整合、解決實際問題）

適用：專案式學習、跨域整合、案例研究、如何運用所學解決真實問題。

### Ⅲ 蘇式起始問句（Unknown Knowns）

| 起始蘇式問句 | 追問策略（依回答分支） | 不問會怎樣 |
|---|---|---|
| 你學的這些東西——你現在能拿來解決你生活中的哪一個具體問題？不用很偉大，很小的問題也可以。 | **→ 想到應用**：「那你第一步做什麼？你現在就做得到，還是還需要準備什麼？」 **→ 想不到**：「那我換個問法：你學 OOO 之前跟之後，你看同一件事的方式有沒有哪裡不一樣？」 | 學了不能用 = 等於沒學。沒有應用場景的知識 retention 極低，兩週後只剩 20%。 |
| 你覺得你學的這個領域，跟你最擅長的那個領域之間——有沒有可以互相用的方法或觀念？ | **→ 找到連結**：「這個連結是你學的時候就發現的，還是現在被我問才想到的？」 **→ 覺得沒關係**：「真的？那你試試看用你擅長的那個領域的語言，重新描述你學的這個概念——你會不會突然發現它們其實很像？」 | 跨域連結是創新的來源。不能連結的人學一個就是一個，能連結的人學一個等於學三個。 |
| 如果你明天就要用今天學的東西做出一個成品——你卡在哪裡？ | **→ 知道卡在哪**：「你卡的那一步，你覺得是因為知識不夠，還是工具不夠，還是不知道從哪裡開始？」 **→ 覺得做得出來**：「那你現在就做一個最簡短的版本給我看看？不用完整，雛形就好。」 | 學以致用的 gap 比多數人想像的大十倍。不問的話學習者一直處在「我懂了」的幻覺裡。 |
| 學完這個之後，你原本對這件事的看法有沒有被改變的地方？——你以前覺得是 A，現在覺得是 B。 | **→ 有改變**：「你覺得是什麼讓你轉變的？是某一個具體的例子，還是慢慢累積的？」 **→ 沒改變**：「真的完全一樣？那代表你學的東西只是強化了你原本的信念，還是你其實沒學到新東西？」 | 沒有被挑戰過的認知不算學習——只是接收資訊。不知道自己原本錯在哪，以後遇到類似情境還是會用舊的錯誤理解去判斷。 |
| 你覺得你學的這個東西，最常被別人誤解的是什麼？ | **→ 知道誤解**：「你自己剛開始學的時候也那樣誤解過嗎？那你是什麼時候發現不對的？」 **→ 不知道誤解**：「那你覺得為什麼會有誤解？是名字取不好，還是概念本身就很繞？」 | 知道常見誤解 = 你已經站在更高的層次看這個概念了。不知道 = 你可能自己就是那個誤解的人。 |

### Ⅳ 蘇式提示性提問（Unknown Unknowns）

| 提示性問句 | 蘇式推進 | 為什麼重要 |
|---|---|---|
| 你學的這個東西，在真實世界裡有人真的用它解決過問題嗎？——他們的用法跟你學的有一樣嗎？ | 沒想過 → 「如果你去找一個真實案例來看，你覺得你最先會發現什麼跟你學的不一樣？」 想過 → 「真實案例的解法跟你學的教科書解法，最大的落差在哪裡？」 | 真實案例永遠比教學範例複雜。落差就是你的 learning gap。考試不會考但工作一定會遇到。 |
| 如果你只有一半的時間、一半的資源——你還能做出同樣的成果嗎？哪裡可以砍？ | 能回答 → 「所以你現在的做法裡，哪些是真正必要的，哪些其實是 comfort zone？」 不能回答 → 「如果明天就上線，你會先做哪 20%？」 | 限制是理解深度的試金石。不能簡化 = 還沒內化。 |
| 你學的這個東西，能不能用來否定或挑戰你原本的一個信念？ | 能 → 「那你原本的那個信念，現在你覺得它是錯的，還是只是不完整？」 不能 → 「那你覺得你學的東西永遠只會支持你既有的觀點嗎？還是你還沒找到那個挑戰的角度？」 | 能用自己的知識 challenge 自己原本的信念 = 真正掌握解釋力。不能 = 只是在強化偏見。 |

## 學習類型判定

Phase 0 靜默判定用。一次學習可能跨多型，此時主段全讀、另一段只挑補充起始問句，概念重複的只問一次。

| 學習表現 | 學習類型 | `type` 值 |
|---|---|---|
| 讀課本章節、聽理論課、讀論文、理解定義與分類 | 概念理解型 | `concept` |
| 學軟體操作、程式實作、實驗步驟、運動技巧、樂器演奏 | 程序操作型 | `procedure` |
| 專案式學習、跨域整合、案例研究、如何應用所學解決問題 | 連結應用型 | `transfer` |
| 以上皆非、跨多類難以歸屬 | 通用 | `general` |

判定不確定時預設 `general`。

## 寫你自己的學習類型段落

### Ⅲ 起始問句怎麼寫

每一題都要通過這個測試：**「這題問下去，學習者需要真正思考才能回答，而不是認出選項？」** 過不了就別收。

| 欄位 | 要求 |
|---|---|
| 起始蘇式問句 | 開放式、口語、讓學習者「產出」而非「認出」。不給選項。 |
| 追問策略 | 列出 2–3 種回答分支及對應的追問方向。追問要能挖更深，不是換句話說。 |
| 不問會怎樣 | 一句話寫沒學到的後果。這是排序依據。 |

### Ⅳ 提示性問句怎麼寫

格式：

```markdown
| **<一個讓他自己發現盲區的問句>** | **<他答了之後你怎麼接>** | **<為什麼重要>** |
```

- 必須是學習者**真的可能沒想到的方向**
- 每一條是一個問題，不是一個建議
- 他的回答不重要——重要的是他因為這個問題而意識到「原來還有這個方向」

### 範本

```markdown
## <你的學習類型名>

### Ⅲ 蘇式起始問句（Unknown Knowns）

| 起始蘇式問句 | 追問策略（依回答分支） | 不問會怎樣 |
|---|---|---|
| <開放式問句，讓他產出> | **→ 答 A**：<追問方向> **→ 答 B**：<追問方向> | <後果> |

### Ⅳ 蘇式提示性提問（Unknown Unknowns）

| 提示性問句 | 蘇式推進 | 為什麼重要 |
|---|---|---|
| **<讓他發現盲區的問句>** | **→ 他想過**：<接法> **→ 沒想過**：<接法> | <為什麼重要> |
```

補完記到「學習類型判定」表加一列。

### 最快的補法

不用一次寫完。跑幾次真實覆盤，把當下真正挖出學習缺口的起始問句記下來，回填。
