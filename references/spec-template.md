# 學習覆盤卡模板（蘇格拉底版）

Phase 5 依此模板生成。**硬限制：一個螢幕讀完**（約 40 行內）。

存檔位置：`<筆記庫>/rdq-learn/RDQ-learn-<主題slug>-<YYYYMMDD>.md`

---

## 逐字模板

```markdown
---
rdq_learn_version: 2
topic: <一句話主題，≤30 字>
type: <concept|procedure|transfer|general>
date: <YYYY-MM-DD>
status: draft          # draft → confirmed
socratic_depth: <平均追問層數，例：1.8>
telemetry:
  mode: <lite|full>
  rounds: <覆盤輪數>
  questions: <起始問句數>
  followups: <總追問次數>
  q4_prompts: <Ⅳ 提示性提問數>
  revisions: 0
---

# RDQ 學習覆盤：<主題名>

## 一句話總結
<用學習者自己說出來的話，不是你的總結。他回答 phase 1 第一題時說的那句就是他最自然的總結>

## ✅ 已掌握
- <知識點> — 來自信箱：<他主動說出／他回答蘇式問句後浮現／他經過追問後自己推出來的>
  <每一條都要記錄它是怎麼被發現的——蘇式對話的精髓在過程>

## ❓ 待確認
- <疑問或薄弱點> — 當時他 <怎麼回答的>，推測可能 <你的判斷>
  <所有他回答「不確定」、或追問到第二層答不出來的項目>

## 💡 蘇式對話中的關鍵浮現
- <他在被追問的過程中自己發現的東西>
  <蘇格拉底對話的特色：他本來不知道自己知道這些——這是追問的功勞，不是灌輸的功勞>

## 🔍 未探索
- <他選擇現在不碰的項目>
  <Ⅳ 提示性提問中他聽了但沒深入追的方向>

## 📋 覆盤摘要
<一段話，包含：
  - 學習者用什麼話總結他學的東西
  - 他在哪個方向上最穩固
  - 他在哪個蘇式追問中自己發現了關鍵連結
  - 待確認的薄弱點有哪些
  - 一句出自學習者自己口中的關鍵引句（他說過最能代表他理解程度的那句話）>

## 📝 下一步行動
- [ ] <1–3 條，從對話中自然長出，不是硬塞的建議>
```

---

## 各段落的功能

| 段落 | 它在解決什麼 |
|---|---|
| ✅ 已掌握 | 讓學習者看見「我到底會了什麼」——尤其追問過程中他自己推出來的東西 |
| ❓ 待確認 | 把蘇格拉底對話中測出的邊界顯性化。追問到第二層答不出來的全部列在這裡 |
| 💡 蘇式對話中的關鍵浮現 | 這張卡最值錢的部分。蘇格拉底的功績不是教了什麼，而是讓他自己發現自己會了 |
| 🔍 未探索 | 防止範圍擴張，明確現在不碰什麼 |
| 📋 覆盤摘要 | 包含一句學習者自己的話——這是「他真的懂了」的最強證據 |
| 📝 下一步行動 | 從對話中自然長出，不是硬塞 |

---

## 寫作要求

- 繁體中文
- 關鍵詞（主題名、人名、專有名詞）一律**粗體**
- **一句話總結必須是學習者自己說的話**，不是你的 paraphrase——他回答 Phase 1「你腦子裡最先浮出來的一句話」就是這句
- 💡 段落記錄的是「他經過追問後自己說出來的」，不是你分析給他的
- 空段落直接省略；示範模式才保留佔位行
